## Findings

- [P1] **The record's primary CTA is unreadable on hover, in both themes.** `buttons.css:140` `.btn-accent:hover:not(:disabled)` sets `background: var(--color-accent-dark)` and never restates `color`, so the bare `a:hover { color: var(--color-highlight) }` at `typography.css:157` (0,1,1) beats `.btn-accent` (0,1,0): `Open publication ↗` (`PublicationRecordRail.svelte:206–215`) hovers to pine-on-pine-dark, **1.48:1** daylight / **2.74:1** midnight (E1). Fix at the cause: `a:not(.btn):hover` at `typography.css:157`, mirroring the `:not(.btn)` exclusion the prose-link rule already carries at `typography.css:227`. Belt and braces, add `color: var(--color-text-inverted)` to `.btn-accent:hover:not(:disabled)` and `.btn-primary:hover:not(:disabled)` (`buttons.css:124`), which have the same hole. Affects 4 accent anchors site-wide; `.btn-outline-*` and `<button>`s are unaffected (they restate `color`).
- [P1] **The facet ledger is the one control family the touch pass missed.** `.facet-row` (`entity-index.css:375–389`, `padding: var(--space-0-5) 0`) measures **23.06 px on a 23.06 px pitch** for 18 of 21 rows at 375 under touch (E2) — under WCAG 2.2 SC 2.5.8's 24 px, and the spacing exception cannot rescue it because adjacent rows share an edge. Every neighbouring control in the same apparatus is 44 px. Fix: add to the existing `@media (--touch)` block at `entity-index.css:272–296`, beside `.language-opt, .sort-opt`: `.facet-row { padding: var(--space-2-5) 0; min-height: 44px; }`. The grid is behind `More filters` below `--lg`, so the extra height costs the reader nothing.
- [P1] **The "All" type chip asserts a count that clicking it does not produce.** `EntityFilterBar.svelte:75` hard-codes `{totalEntries}`, so under `?tag=Islam&year_min=2018&year_max=2021` the row reads `ALL 44` beside `CHAPTERS 2` and `ARTICLES 5` while the summary says `10 OF 44` (E3). Fix: print the sum of the disjunctive type counts (`Object.values(filters.counts.types).reduce(…)`, i.e. the match count with `types` cleared) and give the chip `data-count` so the zero-state ink rule reaches it. Same button is also the only chip on the page without `aria-pressed` (`EntityFilterBar.svelte:68–76`; the language "All" at line 102 has one) — add `aria-pressed={af.types.length === 0}`.
- [P1] **The year slider is the only keyboard-operable control on the site with no focus indicator.** `RangeSlider.svelte:379–384` sets `outline: none` on `:hover, :focus-visible` and signals both states by turning the handle pine — so focus and hover are indistinguishable and keyboard focus is invisible on a pointer-idle page (E4). `ink-signal.css:802–808` states the contrary rule in so many words ("A colour change alone is not a focus indicator: the ring is the same one every other control on the site draws"). Fix: split the selectors — keep the pine swap on `:hover` / `.active`, and give `:focus-visible` `outline: var(--border-width-medium) solid var(--color-accent); outline-offset: var(--space-1)` like `.mono-action`.
- [P2] **No way out of the empty result in the place the reader is looking.** `/publications?q=zzz` prints two lines at identical size, colour and style (`.bib-empty-line`, 21.6 px serif italic `--color-text-soft`, `entity-index.css:549–555`) — the message and its context carry equal weight — inside a 181 px block with **zero controls** (`publications/+page.svelte:275–286`). Fix: demote the second line (mono dateline register, `--color-text-light`) and repeat the one `.mono-action` (`Clear all ✕`, or `Clear search ✕` when only `q` is set) inside `.bib-empty`, calling the same `clearAllNarrowing`.

## Declined

- "More whitespace / fewer facets / thinner rules / one font / drop the sidebar / desaturate" — the brief's standing declines; nothing measured here argues for any of them. No facet on the page fails to discriminate (worst dominant value `Islam` 35/44), and the rhythm is already on the baseline.
- Reducing the masthead type on long titles. The 201-character French title sets 13 lines / 699 px at 1440 and 17 lines / 656 px at 375, which is a great deal of headline — but 3.2 harden explicitly ruled it fine, `--md-down` already steps `--font-size-4xl` → `3xl`, and a further step would put the masthead at or below `.section-title`. Re-opening it is a `bolder`/`shape` decision, not polish.
- Raising `.chip`'s 1px border off 1.69:1 (daylight) / 1.73:1 (midnight). The flat hairline chip is a signature idiom and the selected state is a 17:1 solid-ink swap; SC 1.4.11 reaches a boundary only when it is _required_ to identify the control, and mono caps plus an appended count identify it. Measurement recorded; owner's call, not a defect.
- Motion, a second accent, a shadow or a fill to mark the copy-failure state — finding 6 asks for an ink change only.
- Retiring the eyebrow (playbook's craft-floor move) — `.eyebrow` is a signature Ink + Signal element per the brief.
- Adding `aria-valuetext` per handle on the slider. Both handles announce the whole window (`2018–2021`), which is arguably less precise than per-handle values, but the readout is the control's stated design and changes as the handles move; not worth churn in a polish pass.
