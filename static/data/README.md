# Map boundary data

`world-countries-110m.geojson` is the compact world-country GeoJSON from
[`johan/world.geo.json`](https://github.com/johan/world.geo.json), derived from
Natural Earth's 1:110m Admin 0 country boundaries. Natural Earth data is in the
public domain. The site fetches this file only when a visitor activates a
choropleth map.
